# 正手 M09 手拍证据修订的前端读取

仅 GS01-M09-04（非持拍手主动接近球拍）和 GS01-M09-05（球拍重新进入非持拍手控制）适用 `gs01-m09-hand-racket-observability-v1.0.0`。原先两卡重复使用双腕距离变化条件；它不能识别具体手向球拍接近，也不能证明重新接触或控制。

生成的 GS 显示契约为两卡携带修订标识、各自缺少的观测及原因。读取旧报告时保留这两张卡及实例、原帧账本和来源，清空其旧分数；旧条件转入 `superseded_conditions`，通过位清空；旧条件的完整 measurement 留在 `superseded_condition_evidence`。旧数值显示为“旧规则双腕距离变化记录”，不误标为缺测。其他卡的规则种类检查保持严格。历史文件原字节不改；当前阅读结果采用修正后的计分依据，不把旧重复分数继续计入总分。

后端的 `auxiliary_observations` 独立保留双腕测量行和缺测原因；前端仅展示保存的辅助记录，不宣称重新读取媒体或复算其像素几何。它不能使两卡获得成绩，即使输入保存了高分、通过位、控制布尔值或未知修订号。实际所需手拍数据缺失时显示未评分及具体缺项，不提示人工复核。已有充分依据的其他卡继续直接正式评分。

完整备份保存修订、必要观测、辅助测量、旧条件及来源账本；可读导出明确双腕记录不用于判断手拍接近或控制。当前原卡结构仍有 298 张；历史 native e420 完整报告的 188 个实例和 114 个正式实例不变，因为该报告没有执行这两张 M09 卡。

旧四个固定 MIT M09 窗的 20 个实例经过当前 reader 后保留 3 个正式实例、17 个缺测实例，仅一张卡有分。剩余有分项均为 M09-01 A100，因此可用卡均值为 100。这是移除两个缺乏相应球拍证据的旧 E20 后产生的分母变化，不表示运动员技术改善，也不表示整个随挥动作达到 A。

新的五项前端测试覆盖历史迁移、298 卡保留、伪造分数/修订/通过位不能重新计分、其他卡种类检查以及完整备份与显示。测试中的新辅助封装由旧真实测量构造，用于读取合同测试；实际媒体重算在后端另有来源绑定记录，二者不混为新增真实案例。
