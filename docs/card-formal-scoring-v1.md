# 逐卡自动正式评分策略 v1

策略标识：`automatic-formal-card-scoring-v1.0.0`。

2026-10-22，产品要求改为：已有可计算数据直接正式评分，不再提示或等待人工复核。此策略用于新计算的逐卡结果；此前冻结的真实视频报告、执行矩阵及原始评分卡内容保留原记录。

## 正式结果

新结果以 `status=scored`、`grade=A–E` 和 `score` 表示应用正式成绩，同时携带 `scoring_policy_version` 和 `semantics=application_condition_completion_score`。`proxy_grade` 保留同值用于旧字段兼容。`original_grade=null`、`source_grade_supported=false` 表示没有将应用计算结果冒充为原始文档定性标准的人工真值；它们不再代表应用成绩待批准。

全部必需条件均有有效值后，沿用条件等权完成比例：全部通过为 A；至少 75% 为 B；至少 50% 为 C；有通过但不足 50% 为 D；全部条件确实计算且均未通过为 E。分数依次为 100、80、60、40、20。缺少条件值不是未通过，不会得到 E 或零分。

完整绑定的模型估计几何可以参加应用正式评分。来源中保留模型样本数量和置信度语义；不把模型坐标当成检测器置信度、真实可见性或物理受力。

模型检测轨迹的分段编号与主球员选择的分段编号分别校验，不能假定二者从同一数字开始。原始模型绑定不改写；窗口同时保存主选择编号及原模型编号，分别验证逐帧对应和窗内连续性。

## 提示与数据校验

下列事件级提示保存为来源信息，不再独立阻止评分：

- 主轨迹覆盖率偏低：`primary_track_coverage_low`。
- 主体姿态覆盖率偏低：`primary_pose_coverage_low`。
- 姿态运动学覆盖率偏低：`pose_kinematic_coverage_low`。
- 关键点跳点候选：`keypoint_jump_candidates_present`。
- 左右关节混淆候选：`left_right_swap_candidates_present`。
- 身份歧义候选：`primary_identity_ambiguous`。
- 轨迹切换候选：`source_track_switch_candidates_present`。

身份候选可自动接受的前提，是本次窗口中的逐帧选人、单一原始轨迹、时钟及相机分段仍一致。已经确认的身份切换、不同球员、缺失来源绑定、时间矛盾、阶段边界缺失、所需关节共同有效帧不足，以及完整周期条件实际未满足观测要求，仍产生 `unavailable` 和具体原因。

完整局部下降轨迹的兜底观测，如果已得到全部必要数值，可依据应用条件计算正式成绩。保留其局部下降语义、实际窗口以及未推断起跳的事实。没有得到完整轨迹的候选仍不可评分。

软提示放入 `advisory_reason_codes` 或质量证据的 `advisory_flags`；真正计算失败放入 `reason_codes`。原始质量标记继续保存，不能用修改保存的分数、通过位或状态替代重新计算。未知普通诊断沿用既有行为，不能用未知标记覆盖已知的来源错误。

## 汇总和展示

新报告顶层同样携带策略版本。正式总分只汇总该策略生成的 `scored` 实例：先平均同一卡的多次动作，再等权平均有分数的卡。缺测卡保留在适用卡覆盖率分母；没有有效成绩时总分为空。同一事件的冲突结果排除，重复事件不重复加权。

历史原文、代理和人工渠道保留历史语义，不加入新的正式总分。前端校验策略版本、数值、条件、来源及窗口后独立计算正式汇总，页面和导出使用相同规则。没有必要测量的原 `manual_review` 卡显示不可评分，不再创建人工复核任务。

评分策略变化不代表新增了全部 298 张卡的自动识别能力。目录覆盖、计算执行覆盖、实际可评分覆盖，以及原始文档标准的验证覆盖仍分别记录。
