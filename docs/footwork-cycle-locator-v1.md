# 原帧连续踝运动自动定位 v1

`locate_footwork_cycles` 填补自动候选入口：扫描完整输入原序列，输出每个踝运动段与相邻的完整低速段。每个运动候选、短段和被截断的段都保留。它不改写原事件、人工窗口或历史分数，不分配 FS03 / FS04 / FS05 动作类别，不输出卡片成绩。

原有 `foot_crossing` 只提供投影踝顺序交换；现有 FS03 / FS04 评分入口仍要求显式人工候选。本定位器独立于该未跟踪模块，不引入其依赖，也不把一次静态换序变成完整步法。

## 固定政策与原帧证据

复用已发布的 `continuous-ankle-motion-cycle-v1`：踝速大于 0.5 躯干长度/秒为运动，相邻前低速、运动、后低速均需至少 80 ms，水平位移至少 0.08 躯干长度；动态端点窗口至少 7 帧。没有针对本次视频调整阈值。固定参考为同一连续段的躯干长度中位数；候选外窗由完整相邻低速段确定，再用该精确外窗自己的固定尺度复算。若移动段边界变化或门槛不再满足，候选保持失败，不移动边界追求通过。

六个共同必要关节为双肩、双髋、双踝。原帧、processed index、真实 PTS、原始选人、视频 SHA、raw track、选择与相机 epoch、共同有效关节、相机参考和 12 像素躯干门槛逐行检查。源缺帧、无效模型来源、身份冲突、相机断点或任一共同关节缺失会分段，不能插值或跨接；原始全帧分母与排除原因仍保留。单目模型的有效几何不表示关节可见性或地面接触已证实。

旧事件的 `phase_boundary_censored` 保留在 `associated_event_quality`，不能以另一个动作阶段缺失为由删除完整原帧。新候选的前后低速阶段仍须独立完整观察。确认的身份切换仍在其原始时间窗内阻断；候选身份、跳点等软质量字段保留，不能替代真实逐帧身份闭合。

输出 `segments` 保存完整原帧绑定、两种时钟、原始 primary 行、原模型绑定、六关节参考点、原置信度和模型 mask。点已变换到固定相机参考，不得再次应用相机矩阵。`candidates` 保存运动窗及前后低速帧、原数值、候选窗复算和所有拒绝原因。`tennis_family_assignment_count=0`、`scored_card_instance_count=0`，完整运动候选数量不是新增可评分卡数。

## 真实消费者与来源区分

`scripts/replay_footwork_cycle_locator.py` 是真实文件入口。它核对四个原文件、summary 中的视频和 frames 散列，再次解码原视频取得 PTS；复用既有 `_prepare_samples` 和 `_bind_verified_decoder_snapshot`，不信任保存的候选或分数。运行结束再次核对文件散列，并记录实际导入模块的字节及 UTF-8 LF 散列。直接序列调用始终 `file_artifacts_verified=false`；真实文件重放才标记已验证。

2026-10-24 的开发结果分别保留三次输入，未合并两个相同视频的姿态导出：

- native `e4204ec3-7d84-4a90-a961-9dad01b43c2e`：2,911 原帧，261 个运动候选，其中 63 个满足完整视觉运动政策；198 个失败，770 帧因原证据缺口排除。视频 SHA 为 `71d3f59b7a8b966ef7645cac412cb03679376f70a2f080d270391a32697d7fa9`。
- production `0a3df3a3-2629-4dd5-80a1-54e4b11f7341`：相同视频的不同姿态导出，2,911 原帧，274 个运动候选，62 个完整、212 个失败，691 帧排除。不能替换 native 的轨迹或合并为两个独立视频。
- USTA `extension-fs-usta-return-footwork-heldout`：539 原帧，58 个运动候选，0 个完整。原帧 11940、12110、12111、12279 的共同关节不足，保留为断点；其余候选也没有完整满足固定前后低速条件。这个结果不证明真人没有做步法，只说明该姿态轨迹未建立规定的连续证据。原六个人工窗口不变。

便携真实 fixture `tests/fixtures/footwork-cycle-locator-native-e420-v1.json` 只取 native e420 原 112–136 帧，保留原 70 关节点、绑定、请求、选人、相机与检测字段，删除冗余数组和 3D 测量，并保留每条原 JSONL 行与四个原文件散列。右踝 124–132 是运动，前 400 ms、运动 266.667 ms、后 133.333 ms；此精确局部窗净位移为 0.20873 躯干。左踝同时留下一个缺前低速段的失败候选。

112–136 是首次开发定位时继承旧事件 phase-censored 封锁留下的子窗，已逐原图审阅并固定，之后没有移动。解除与新运动无关的旧阶段封锁后，native 与 production 完整重扫的同一右踝运动外窗均从 79 帧开始；这个变化来自旧阶段备注的处理，并非视频/身份断点改变。当前完整 run 的自动窗 79–136 与固定开发 fixture 112–136 分开记录，不能将后者改称当前自动外窗，也不能把两种姿态导出混为同一输入。

独立查看 112、124、128、132、136 原图可见同一近端练习者和场地线。该观察不赋予步型、触地、目标、专家等级标签。自动定位后的方向/目标参考将由另一个有来源的显式输入提供，本批未接正式卡片评分。

## 验证

专项测试包含真实 native 正运动与左踝失败、原 USTA 36 帧全部失败、真实模型请求损坏、真实窗口尾部截断、原 PTS 独立重算速度与边界、原帧/身份/epoch/相机/共同关节缺口、静态交叉、原阶段 censored 与确认身份切换的区别，以及两个实际原视频文件入口。合成序列仅验证数学与反例，不计入真实样本。

完整 clean 重放、逐模块来源闭包、图像与精确文件清单位于未跟踪目录 `.codex_tmp/footwork-cycle-locator-20261024/`。该目录中的 `first` 开发重放保留当时旧阶段 censor 整窗阻断结果；最终版本改为保留关联备注，未改原视频、轨迹、周期阈值或既有人工窗口。
