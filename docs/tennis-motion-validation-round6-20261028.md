# 单手侧冲突、切削空间轨迹与接发实拍复核（2026-10-28，第六轮）

本轮修复了 Sharapova 开发片段中自由平衡臂抢占真实右手前挥的问题；普通 B 的持拍侧仍未可靠确定。补充四条新源视频的真实推理，其中一条明确慢放只用于空间轨迹实验。新增接发和武汉切削暴露的自动漏检、误报均保留，不能称作全部自动验证通过。评分曲线、聚合权重及职业/普通人的分差均未用于选择规则或素材。

## 单手侧冲突

Sharapova 原片约 16.05、16.08 秒的球拍检测框与模型头部标记重叠，最近腕关联把这些框支持给了自由左臂。随后同一连续窗口的两个不同原帧，存在只与右前臂延长方向一致的真实检测框。新规则将头部重叠标记为语义歧义，不能把它当作已确认的持拍手证据；也不声称模型已识别真实拍柄或证明检测框是假球拍。

常规近框提案及原排序保持原有含义。替代运动腕只在头部歧义之后、同人物和连续源窗口内有至少两帧独立方向支持，并同时满足既有跨身几何与完整阶段规则时才参与选择。不按腕速、职业身份、人工手侧或分数择优。球拍置信度 0.25、近框范围 0.35 躯干、两帧支持、650 ms 范围等原条件未放宽。

修复将旧 15849/16116/16550 ms 左腕准备窗改为约 **16149/16483/16717 ms 右腕真实前挥窗**，原 13.981 秒双手动作保留。源图独立复核确认右臂与球拍连续、左臂独立平衡；新增类型绑定引用本轮源审计，没有迁移旧准备窗的标签。候选物体支持与最终报告阶段内的物体覆盖分别输出：两帧替代支持在候选窗口内、报告阶段结束之后，不能称为阶段内球拍观测或触球证明。

普通 B 的 70 帧独立 RTMPose-L 推理与原 SAM 输出多数同名关节位置接近，但两模型一致不是解剖真值。腕带颜色、靠近拍头和单帧投影均不足以确认握柄手。另看 19 帧发球/恢复控制图仍未可靠排除遮挡与交臂歧义。因此**撤回第五轮“已证实 native 左右交换”的断言**，更正旧文档；原始证据、人工手侧记录和冲突拒测保留，不交换 native、不删除冲突换取评分。

## 正手切削：空间正例与自动误报分别报告

[Tennis.com / Tennis Channel 的 Newcombe 教学原片](https://www.tennis.com/news/articles/the-forehand-slice-moonball-body-serve-5-underrated-tennis-tactics) 的侧视移动段有真人、来球和完整可见的持拍臂。前段有教学冻结及箭头，故固定使用显示时间 60.4–61.3 秒的 **28 个实际移动源帧**，仅测空间路径。独立球场纵线与围栏柱确定前向/向上方向，不以腕轨迹反推方向；基底条件数 1.417，低于原上限 4。既有正手切削公式测得腕的前向进程比例 0.927、下向进程比例 0.989、联合代理值 0.957。

这不是球拍头轨迹、真实受力或完整动作评分。慢放倍率未知且缺少连续真实准备，`overall_score=null`，未调用完整阶段评分，也不验证真实毫秒时序。场线角色由人工场景判读，网未入镜；该限制保留。容器原始 PTS 比显示相对时间多 10 秒，逐帧像素和 PTS 已核对，继续使用已有原点转换；没有为了测量移动帧窗口。

[武汉近端切削原片](https://www.wtatennis.com/videos/4593081/hot-shot_-jelena-ostapenkos-forehand-slice-winner-on-the-run-in-wuhan) 的真实右手切削约在 6.72–6.84 秒。固定人工窗 6440/6600/6800/7080 ms 在实际 native 上有 17 帧；前向与向上投影条件数 5.667，大于原上限 4，肩轴又短缩，最终仅通用阶段连续性可测，覆盖 1/5，不能算切削专属指标成功。

**武汉自动输出另有一个真实误报：5680/6000/6480 ms 左空手跑步摆臂被计成完整动作并得 93.28。** 原始自动结果保留，不计作验证成功。源图复核将该精确窗口标为 invalid 后，现有有效性检查正确排除评分与训练建议；这是人工证据阻断，不是自动算法已修复。真正右腕前挥只有 6800 ms 一帧合格拍框，同帧两个重复框不能冒充两帧。拍头近腕误关联和快速挥拍的物体漏检仍是待解决问题，没有降低两帧或距离条件补分。

## 接发、来球与时序

新增 [Adelaide 四次接发原片](https://www.wtatennis.com/videos/4195008/watch-this-jelena-ostapenko-closes-match-with-four-straight-return-winners) 和 [Toronto 接发原片](https://www.wtatennis.com/videos/4556617/hot-shots-alexandrova-spams-return-to-sender-button-against-powerful-sabalenka-serve)，各取第一个连续可见发球后近端接发的片段。捕获窗分别为 0–4.0 秒、23.0–26.6 秒，在推理前登记；细原帧边界复核并行进行，复核者未读模型和评分，未冒充所有细标签均在推理前完成。

两条新源实际保存 500、450 条 native，包含对手上下文。源画面可确认连续发球与接回，但**自动候选均为零**：Adelaide 的紧凑双腕轨迹达不到既有横向候选条件，已有 paired-arc 规则也未满足，不能简单移用；远端发球仅一帧合格拍支持。Toronto 真实挥拍附近缺少合格拍支持，远端发球姿态还有间断。来球链也不完整。这些是当前观测/识别能力的缺口，不能说源视频没有接发。

独立源发球帧和来球点通过原有人工关系验证后，两条固定双反接发窗的专项覆盖分别为 **4/9、5/9**。主持拍手未知，左右测量腕并列保留，不选分高的一边，不产生人工确认的柄底手或单一总分。髋肩腕时序均仍缺测：Adelaide 的髋、肩轴分别缩短至约 0.059、0.103 躯干长度；Toronto 肩轴约 0.140，低于原 0.3 门槛。不能把不可辨认的投影峰强行排序。

Dimitrov 原片的源图能看到部分运动模糊来球，原检测器漏掉了其中不少点。本轮对固定 79 原帧分别用官方 YOLO26 n/s/m 与 960/1920 尺度做对照，置信度 0.45 和关联条件不变。检测数增加不代表同一球的连续链；较多点的 s/1920 仍有 216 ms 空洞超过原 180 ms，且出现轨迹 ID 断开。未更换生产模型，也未用预览插值填评分证据。

时序代码另修复一处数值错误：在 30/60 fps 的实际 PTS 除法下，恰好一帧的峰间隔会因浮点误差略大于中位帧间隔而被误判可分辨。加入 1e-7 ms 数值容差维持原“一帧内不可分辨”的定义，不改变运动学门槛或评分曲线。旧 ICS 冻结峰结果仍为 60；Dimitrov 髋肩同峰仍缺测。

用户原资料的发力/运动要求继续由 `contracts/scoring-reference-20261004.json` 对应：正手切削前下路径 VIS-GS P0283，双手配合 P0127/P0145/P0154，接发依来球压力缩短准备 VIS-RT P0036。资料未给出的数字不冒称教练标定值；没有来球压力标尺时仍不评分该项。
