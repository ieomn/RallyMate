# 应用正式评分读取与展示

新报告以顶层及每实例 `scoring_policy_version=automatic-formal-card-scoring-v1.0.0` 区分历史数据。有效实例使用 `status=scored`、`grade/score`，`proxy_grade` 仅兼容已有消费端。原卡 `original_grade` 继续为空，`source_grade_supported=false`；应用评分语义是 `application_condition_completion_score`。读取器从已核验条件重新计算等级，不把保存的等级或 pass 位当作计算来源。

同卡多个有效实例先求均分，再对有效卡等权平均。正式卡数、实例数和总分在浏览器重算；外部摘要计数不会成为事实。重复一致实例只计一次，冲突实例取消评分。缺测不计零或 E。历史无政策报告继续保留 `proxy_scored`、复核或缺测语义。

七类候选覆盖/跳点/换侧/身份疑点在新政策中保留为来源备注，不阻止完整可计算窗口评分。逐帧选择、单一匹配原轨迹、PTS、帧库存、相机分段、指标共同关节和原质量覆盖仍必须闭合；confirmed switch、混合/错误原轨迹、截断阶段及无法计算的实值不会被正式政策放行。完整模型测量可正式评分，但模型缺置信度例外必须核验每帧模型来源，而不是相信自称的 mask 或模型字符串。

FS01-M02 的局部下降 fallback 独立检查整个父事件库存、原事件搜索上界、相机参考、每帧模型来源及 PTS。读取器重新选择最早完整下降与转折确认窗，用固定躯干尺度和真实 PTS 重算髋下降、左右膝变化、同时下降时长比例、相邻速度变化比。保存 selected、complete、passed 或替换总分不能替代这些检查。源坐标已在相机参考平面，不重复施加变换；它不证明起跳或完整垫步技术。

主逐卡面板默认展开，直接显示正式总分、等级和分数。来源、不确定性、原始质量备注及完整证据保留在详情和备份中。训练概览的新政策分支展示该面板，避免把旧同项复核建议当作正式评分的前置要求。旧政策页面分支不变。本次没有宣称应用所有历史文案均已迁移。

`scripts/build_fs_step_motion_display_fixtures.py` 生成 22 个合成 FS4 正式合同例；`scripts/build_formal_card_display_fixtures.py` 生成 5 个合成 FS03/FS04 周期报告及提交轨迹 fixture 的 0a3 重新计算报告。0a3 是原记录轨迹重放，未在此过程重新解码原视频；其五个有效卡分数为 40/100/40/100/60，均卡总分 68，另外两个缺测实例无分。合成例不算真实技术阳性，完整真实 FS4 阳性仍为 0。旧 JSON fixtures 不改写。

提交的 0a3 前端 fixture 仅投影五张有实例的卡，用于合同测试；它不代表全目录覆盖率。实际预览和完整备份验证使用 298 行原报告，正式评分覆盖为 5/298，而不是 5/5。GS 的四个合成来源合同例也不计入真实阶段样本。

导出读取当前验证结果，保留正式评分、总分算法、条件和来源。备份保留完整原证据；再次读取时重新核验，不能仅因来自备份而免检。`report-export.ts` 与训练概览存在先前未提交工作，交付同时保存 HEAD 最小候选和仅针对本次分支的工作区集成补丁，不覆盖其它改动。

模型 detector epoch 与下游主球员选择 epoch 分开保存。只有显式 `detector_track_epoch_primary_selection_applied_downstream` 契约才接受两个命名空间不同；原模型 binding、几何序列和逐帧来源中的模型 epoch 必须一致且连续，主选择 epoch 仍匹配完整父窗。缺 marker 的历史数据沿用原相等契约。

五张时间序列卡的正式格式必须保留 `temporal-source-frame-bindings-v1.0.0`：浏览器核验主窗口及后继间隔全原帧、双时钟、原轨迹/主选择与分段连续性。局部下降另按父事件原坐标重算五值；其余四卡的原几何计算仍由服务负责，浏览器没有冒称重新解码或全面重算其原轨迹。

新政策 GS 与逐卡 FS 的窗口和每一原帧必须提供相同的 `derived_selection_epoch`；全部删去也不可降级为历史可选分支。GS 的 `source_stage_evidence` 保留完整期望原帧、逐帧来源及解码 PTS，随备份保留并在详情可查看。该变化以新正式政策为边界，旧代理报告不被追溯改写。合法的人工 M01 辅助测量在父卡因无完整可计算条件而不可评分时仍显示测量，且独立校验父阶段完整账本，不生成辅助等级。
