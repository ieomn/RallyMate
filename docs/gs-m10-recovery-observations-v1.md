# GS01 / GS02 / GS03 M10：身体恢复观察与手拍证据边界

本修订显式覆盖 13 张 M10 卡；原文、effective 技术字段和其余 285 个卡对象不变。目录总版本仍为 `card-rules-v1.0.0`，只为这 13 张增加 `gs-m10-observability-v1.0.0`。应用成绩始终不等于原文技术等级，`original_grade=null`、`source_grade_supported=false`。

旧条件把“身体旋转恢复”与“重心恢复稳定”都映射为髋速度标准差、躯干摆动及髋投影支撑。该映射没有观测肩髋轴是否返回，匀速快移也可能因标准差为零满足稳定条件。双腕靠近同样不能证明握拍、三角区接触或完整准备状态。本版本将这些含义分开。

## 精确卡映射

- 旋转：GS01-M10-02（T050/P2516）、GS02-M10-02（T099/P4704）、GS03-M10-03（T148/P6891）。独立计算相对源准备参照的肩、髋二维轴返回。
- 身体稳定：GS01-M10-03（T051/P2560）、GS02-M10-03（T100/P4748）、GS03-M10-04（T149/P6935）。计算完整阶段末段的身体投影运动、支撑关系及躯干摆动。
- 手拍控制：GS01-M10-01（T049/P2472）、GS02-M10-01（T098/P4660）、GS03-M10-01（T146/P6803）、GS03-M10-02（T147/P6847）。分别需要双手重新控制、持续双手控制、非持拍手与 RK013 拍喉接触、持拍手与拍柄的连续关系；人体 17 点不能提供这些必要证据。
- 完整准备：GS01-M10-04（T052/P2604）、GS02-M10-04（T101/P4792）、GS03-M10-05（T150/P6979）。原行为同时包含手拍控制或准备握拍，不能以身体稳定和腕距替代。其完整评分暂不可用。

GS01-M10-04 的原技术定义误含“GS-02 双手反手”；既有 effective 工程修订保留不改。GS02、GS03 M10 的原始开始、结束为空，已有工程阶段边界也保留其来源标识，不冒称原文已有精确边界。

## 固定计算政策

核心 `gs_recovery_evidence.py` 导出 `VERSION=gs-recovery-evidence-v1.0.0` 和 `POLICY_VERSION=gs-m10-projected-recovery-v1.0.0`。数值政策在读取本轮候选姿态或成绩前冻结，未根据 MIT 短窗调整。

恢复窗至少 7 个连续原帧。准备参照至少 3 个连续原帧且实际 PTS 跨度至少 80 ms。所有计算保留完整 decoder 分母，不插值、不删除坏帧。旋转要求肩、髋 4 点整窗共同有效；身体稳定要求肩、髋、踝 6 点整窗共同有效。延续原始身份、真实 PTS、双 epoch、固定相机、模型绑定及同帧重复人体归属硬门。

归一化证据保存实际 `_sample` 的 full-torso `center/scale/points` 与 `reference_points`，并复核两套坐标闭合。计算中的固定躯干尺度是该完整窗肩中心至髋中心长度的中位数。`reference_points` 已在相机参考平面，不能再次变换。所有相邻位移及速度均使用原始整数 PTS 和 time base 的差，不使用四舍五入播放时间代替。

端点帧数为 `max(3, ceil(N * .2))`。身体稳定的三项条件分别为：

- 末端内部相邻髋速度中位数不高于 0.6 躯干/秒。
- 末端髋中心 x 位于双踝 x 闭区间的帧比例不低于 0.8。
- 末端躯干相对图像竖直倾角范围不高于 15°。

0.6 沿用已有时序低髋运动工程阈值，0.8、15°沿用既有图像支撑与摆动条件。这些是应用灵敏度参数，不是教练校准或原文分档；投影区间不等于足底接触、承重或真实质心稳定。

旋转需要独立准备参照。肩轴、髋轴按 180° 周期连续展开；投影轴长度小于 0.18 固定躯干时不可计算。参照自身轴范围均须不超过 8°，参照方向取展开角中位数。恢复窗每帧误差为 `abs(wrap180(axis-reference))`，四条件为：

- 肩轴误差起端中位数减末端中位数不低于 8°。
- 髋轴误差起端中位数减末端中位数不低于 8°。
- 末端所有肩髋误差的最大值不高于 15°。
- 末端肩轴、髋轴展开角范围的较大值不高于 8°。

8°为预定轴变化分辨尺度；15°为明确冻结的工程端点容差，非原文角度标准。最后一项区分稳定接近参照与快速经过参照。即使完整满足，也只说明相对该参照的二维轴投影返回，不能确认三维胸廓/骨盆朝向。稳定但仍偏离参照的收尾可以在身体稳定卡满足条件，同时在旋转卡失败，二者不再重复。

## 独立准备参照来源

GS stage 严格白名单新增可选 `recovery_reference_observation`，仅用于 GS01/02/03-M10：

```json
{
  "version": "gs-ready-reference-v1.0.0",
  "method": "manual_visual_observation",
  "action_id": "same-source-action",
  "person_track_id": 1,
  "video_sha256": "原视频 SHA-256",
  "start_frame": {"frame_index": 7, "pts": 0, "time_base_num": 1, "time_base_den": 90000},
  "end_frame": {"frame_index": 10, "pts": 0, "time_base_num": 1, "time_base_den": 90000},
  "source": "带原帧依据的来源记录",
  "source_description": "独立动作前身体准备方向的图像观察",
  "uncertainty_ms": 67,
  "semantics": "independent_pre_action_body_ready_reference_not_technical_ground_truth"
}
```

以上仅结构说明，PTS 占位不构成可执行输入。首尾必须逐项等于真实 decoder 记录，末帧实际 PTS 必须严格早于父 action.start_ms。不能将 M10 自身末端当参照，也不能自动将侧身 M03 改名为准备参照。误差只展示，不扩大取样窗。未知字段、成绩、pass 位或质量豁免全部拒绝。

不仅两个端点同 epoch：从参照第一帧到恢复末帧的原始账本和逐帧 source sample 必须完整，原选人、primary epoch、派生连续 epoch、相机 epoch 及源模型 epoch 必须连续匹配。即使账本首尾和每行时间都齐全，缺失任一中间 sample 也会返回 `ready_reference_intervening_source_sample_missing`，条件值和分数为空，缺失行仍保留在全帧分母。桥接段只证明逐帧样本身份与来源连续，不要求中间动作的全部测量关节有效。中间缺原帧、换人、模型坏绑定或人体归属冲突都会阻断旋转配对，不污染独立有效的身体稳定测量。

输出 `recovery_evidence.stage/reference` 保存全帧几何、source binding、PTS、轴角、展开角、角速度、误差、固定尺度、髋原始位移向量和实际 dt。reference 另保存完整 `continuity_timeline` 和 `continuity_source_geometry_series`，不能删掉模型 marker 或只比较首尾。父 `source_annotation.action_window`、`requested_window_ms` 与原参照 observation 分别保留，供消费者独立核对。

七张缺手拍或完整准备必要观测的卡保持 `status=unavailable`、所有 grade/score 为 null，原因按卡区分；实际腕和身体几何放入 `auxiliary_observations`，带独立版本、含义与 `scoring_eligible=false`。它不混用 M01 的 `auxiliary_evidence`，没有 passed 或辅助成绩，也不会通过低腕距转成握拍真值。缺参照的旋转卡同样保留可算轴几何，条件值为空，不以缺测当 E。

## 验证与真实来源限制

新增两个测试模块分别验证解析可知的数学轨迹、严格原记录入口。数学例包括独立方向返回、稳定侧转收尾、匀速快移、过零摆动、180°边界、源副本不一致、少于 7 帧、缺点、缺参照、原 PTS 非零原点、bridge 缺帧/换人/epoch 变化、完整与混合模型源、外供成绩拒绝。它们只证明合同和数学，不能作为真实网球阳性。

本轮独立视觉观察保留 MIT 双反旧工程终点候选 36–38、93–95、149–153、204–207，分别为 3/3/5/4 原帧。准备方向候选 7–10、50–52、106–109、169–172 由实际原 PTS 绑定。下一步可见脚移动可能仍属于恢复步，而非新独立 FS 动作；因此这些窗口仅作为**旧工程边界候选的短窗拒绝负例**，不认证完整 M10，不计真实完整阶段或新增正分覆盖。root 的独立 fixture `gs-m10-mit-short-windows-20261024.json` 保留该限制。边界语义纠正须另版本、另来源观察，不能从缺分反推或延长窗口。

历史报告与缓存隔离依赖 13 卡专属 revision、canonical catalogue SHA 及新引擎/政策版本。消费者需保留旧实例和证据，但不得将旧重复稳定/腕距成绩解释为本修订成绩；其他 285 卡不被全局失效。
