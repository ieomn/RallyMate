# GS 局部下降辅助观测的显示与备份

本批接入五张 M01 人工复核卡的 `auxiliary_evidence`，不增加任何评分路径。父卡等级和分数仍为空；辅助工程参考值不显示为“通过”，辅助状态不加入代理评分数量。统一报告外壳仍为 `card-execution-v1.0.0`。

读取器保留完整原始辅助记录及父动作窗口，另在每次读取时重算 `auxiliary_validation`。保存的 validation、评分资格或通过标志都不能授权结果。合法记录可逐字段与后端原始记录比较；非法记录保留在备份与“未经验证的输入记录”详情中，摘要、表格和导出不把其中的值展示为有效测量。

有局部辅助观测的目标卡额外保留父 `source_annotation.requested_window_ms`，表示人工请求的完整 M01 范围；父 `window` 仍表示该范围内首尾实际解码帧。读取器把辅助 `stage_window_ms` 与父人工范围逐值核对，并继续要求局部原始 PTS 在父实际帧范围内，父相机补偿有效。人工边界落在帧间时无需强行吸附到原帧。旧报告缺少可选的父请求范围时，只在辅助阶段边界与父实际帧边界相差不超过 0.51 毫秒的情况下接受。没有辅助观测的旧报告不新增字段。人工来源和说明均遵守后端 512 字符上限。

显示契约由 `scripts/build_gs_preload_display_contract.py` 从后端五张支持卡、原始来源摘要、八个必要关节和三项参考值生成。读取器核对版本、M01 卡片与动作来源、父阶段包含关系、原视频和人物、逐帧 PTS/时基、选人及相机分段。八关节有效帧使用交集，完整闭区间保持原始分母；不足七帧、少于 80 毫秒、缺帧或必要关节缺测不能显示为连续有效测量。

辅助汇总不直接采用保存数值。前端按后端相同语义重算：固定躯干尺度取逐帧尺度中位数，首尾各取 `max(3, ceil(n×20%))` 帧；髋下降为端点中位数差除以固定尺度，膝屈曲为端点中位数差。联合下降比例只累计同一相邻原帧区间中髋 y 和双膝屈曲都严格增加的实际 PTS 时长。原时钟和原序列完整保留，不换算为播放器零点。

浏览器只能核对报告内部的绑定和算术一致性，不重新解码视频或独立确认真实关节、身份、垫步、触地、受力和专家阶段。父阶段不可用时，局部有效几何不能提升为有效的阶段辅助汇总。

`gs-preload-synthetic-contract.json` 的主例直接来自已审查的 `synthetic-contract-example.json`，保留上游 SHA；另外九例由真实后端函数重新计算合成姿态，覆盖其余四张卡、六帧短窗、关节缺失、父阶段缺帧、非零原点的非均匀 PTS 以及合法帧间人工边界。测试统一外壳明确不等于生产 HTTP 报告。本批真实 M01 实例数为 **0**，没有真实技术阳性声明。

前端回归覆盖外部评分/通过授权、错来源和阶段、首尾帧丢失、关节并集冒充交集、尺度/中位数/联合时间比例被改、父阶段无效，以及备份和导出。非法辅助值不会影响原有父卡评分边界；旧报告没有该可选字段时保持原有行为。

运行 `python scripts/build_gs_preload_display_contract.py --check` 核对生成契约。重建合成样例需显式传入已冻结的源例路径：`python scripts/build_gs_preload_display_fixtures.py --example <synthetic-contract-example.json>`。定向前端测试为 `gs-preload-evidence.test.mjs` 与 `gs-preload-export.test.mjs`；导出测试应使用本批 `report-export.ts` 最小候选改动。
