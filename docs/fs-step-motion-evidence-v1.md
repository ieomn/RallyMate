# 四张 FS 卡的原帧迈步运动证据

适用卡为 FS02-M04、FS07-M02、FS08-M02、FS08-M03。`step-motion-evidence-v1.0.0` 只验证固定相机参考下的二维踝运动，不能确认脚底接触、发力、目标方向、技术步法或原卡等级。策略 `single-low-move-low-2d-v1.0.0` 是未校准的工程观察策略；尚无独立标注的真实完整正例。合成测试不能计入真实视频覆盖。

## 输入及来源

`fs-card-window-annotations.json` 的上述四卡窗口可选 `step_motion_observation`：版本 `manual-fs-step-motion-v1.0.0`，方法 `manual_visual_observation`，人工观察的 `moving_foot`（left/right），1–512 字符的 `source_description`，严格递增且在父窗口内的 `source_frames`，以及语义 `observed_moving_foot_not_front_foot_target_direction_or_contact_truth`。每个观察帧只含 `frame_index/pts/time_base_num/time_base_den`，必须与原解码帧精确一致，且该帧被声明侧的踝点有效。

父窗口继续绑定原视频 SHA、来源运行、四个原始文件 SHA、人物、帧边界、人工来源版本及时间不确定度。观察进入规范 JSON 摘要。外部 `score/passed/complete/verified/quality_flags/phase_boundaries` 均不能授权计算。FS08-M02 与 M03 如引用重叠的同一步运动，必须共享人物、起止边界和声明侧；不从速度最大的脚推测持久“前脚”身份。

## 逐帧验证

1. 保留闭区间内全部原帧与真实 PTS；不插值、不选子窗口、不以缺测后剩余帧数代替分母。双肩、双髋、双踝共六关节取共同有效交集。70% 只用于几何诊断；运动证据要求每帧六关节及固定参考坐标全部有效，并通过已有身份、相机参考、时钟和最大间隔检查。
2. 至少七帧。固定躯干尺度为窗口逐帧肩中点到髋中点距离的中位数。每个相邻帧对的二维踝速度由欧氏距离、实际 PTS 时间差和这个固定尺度计算。
3. 低速为 ≤0.5 躯干单位/秒，移动为 >0.5。声明侧必须恰有一个连续移动段，前后低速段分别延伸至原始首尾帧。三段均至少 80 毫秒、至少三个实际原帧；短暂停顿不合并，多次运动不挑选。相邻段共享边界帧但不重复计时间。
4. 起止端点各取 `max(3, ceil(N*0.2))` 帧坐标中位数，固定窗口不可缩短，且必须全部落在对应低速段。端点距离须大于两个低速点云围绕其端点中位数的最大半径之和，静止或往返原位不能证明一步完成。
5. 另一只脚如也形成完整三段运动，或其净位移、全路径任一大于声明侧，标记冲突并留空。两种原公式都跨脚取最大值；声明侧较长的弯曲路径不能授权未完成周期的另一只脚提供更大的净位移。不能静默换脚。

输出保存六关节共同帧列表、完整帧/PTS、逐帧固定参考点、逐帧尺度、相邻对速度与时间、所有段的帧和时长、端点中位数、低速点云半径、两脚净位移及全路径、原始声明和全部拒绝原因。`complete_visual_motion_cycle` 每次从原始序列计算；它不是接触或技术等级事实。原来源事件的质量警告在计算后再次拦截分数，并保留原始诊断。

## 公式保持不变

- FS02-M04、FS07-M02：两脚端点中位数二维位移的较大者 / 固定躯干尺度，工程条件 ≥0.15。
- FS08-M02：同一公式，工程条件 ≥0.6。
- FS08-M03：两脚完整轨迹长度较小者 / 较大者，工程条件 ≤0.3；较大路径不足 0.1 躯干单位则缺测。另需同窗躯干倾斜范围 ≤15°。

完整而数值低于条件的窗口可按现有工程条件完成度得到 E；缺帧、不完整或存在冲突的窗口始终留空。原始技术等级始终为空。FS03/FS04 的连续周期验证及原有五张时序卡不使用这个新策略。

## 验证边界

`test_step_motion_evidence.py` 验证纯竖直/斜向、静止、往返、截断、多次运动、单帧跳变、端点窗口不缩短、7/6 帧、79/80 毫秒、变帧率与非零 PTS、全路径与净位移区别、错误侧与双脚冲突、六关节交集、身份/相机/时间错误和外部通过标记。`test_fs_step_motion_windows.py` 使用明确标为合成的原始记录验证四卡公式、来源摘要、原始质量拦截、观察 PTS 和共享窗口约束。

持续高速段内的弧线或折返仍是同一移动段，本策略不声称识别独立的技术动作；完全往返原位由端点不可区分规则拒绝。独立审查的“声明侧净位移 0.4/路径 1.2，另一只脚持续移动净位移 0.7/路径 0.9”反例现在留空，不能借另一脚把 FS08-M02 判为 A。

无可核验的真实正例时，不扩展视频窗口、不修改阈值、不提高真实计分覆盖。前端读取端须独立验证这份完整证据后才能接受新增代理分；该后续接线与当前后端实现分开交付。
