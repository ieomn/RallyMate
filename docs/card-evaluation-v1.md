# 逐卡视觉代理执行与汇总 v1

`card_evaluation.evaluate_card_window` 从原始逐帧关节坐标计算目录声明的条件，不接受调用方保存的 pass、等级或总分。该模块只生成明确标注的视觉代理结果；`original_grade` 始终为空。原始 Word 的 A–E 定性要求保留在版本化目录中。条件完成度对应的代理 A–E 与原文技术等级不是同一量。

## 输入、阶段与时间

输入包含卡规则、同一球员的 Sample 序列、阶段窗口及完整原始解码帧时间线。窗口记录视频 SHA256、事件 ID、球员 ID、选择时期、相机参考时期、起止时间和阶段定位方法。接受有版本的检测器或明确人工锚点；三段挥拍估计不能自动成为十阶段标注。GS 窗口使用 `GS01-M03` 等完整阶段代码；FS 窗口使用 `FS01-M02` 等卡级子窗。

原始帧索引必须逐帧递增1，时间线包含实际解码 PTS 和时间基。缺少姿态的原始帧保留在分母，不能删除后提升覆盖率。原始PTS与播放毫秒必须具有固定时间原点，允许最多1.02毫秒的两端舍入差。80毫秒时长门槛和速度分母使用PTS差值。缺少PTS、不同视频、主体或相机切换、重复帧和不连续时钟均拒绝评分。

跳帧推理目前不能使用本执行器宣称完整原始帧覆盖；必须另建明确采样契约。模型坐标仍是单目几何估计，不能替代可见性证据。

## 每卡共同有效帧

先取所有必需条件的关节并集，再在同一物理帧上检查该并集。全部条件仅在这些共同有效帧重新计算；分母始终是原阶段的全部解码帧。共同有效比恰好70%可通过几何门槛，低于70%不生成等级。

有限坐标、关节置信度至少0.35，或具有对应来源绑定的模型几何，只建立本模块的**几何可用性**。当前原图边界检查由上游姿态生产器负责，本模块不独立证明它，因此输出 `image_bounds_verified=false`、`visibility_verified=false`。不得据此声称原文70%真实可见性已经满足。

静态均值、中位数和范围可在共同有效帧达到70%时计算。首尾变化、轴线展开和动态轨迹要求完整连续帧；不跨缺测拼接。首尾统计各取20%窗口且至少3帧。固定参考的髋/腕/踝运动用相机参考像素计算，按整窗固定躯干长度中位数归一化。髋下降不使用移动的踝作为地面。步周期指标要求起止锚点与输入窗口端点一致，防止周期外运动混入。

## 代理等级和分数

全部必需条件均有合法测量且质量门槛通过后，才计算工程条件完成比例 `p = 通过条件数 / 全部必需条件数`。条件权重相等：p=1 为A；0.75≤p<1 为B；0.5≤p<0.75 为C；0<p<0.5 为D；p=0 为E。A/B/C/D/E映射100/80/60/40/20。

这些数值是版本化工程映射，不来自原文，也不是专家校准的网球技术分。缺一个必需条件、未知测量算子、单位不匹配或阶段缺失，结果都是 `unavailable`，分数为空，不能落到E。真实注视、受力或拍面三维等要求额外观测的规则输出 `review_required`。五张FS连续窗卡由专用执行器计算联合时序，并通过服务适配器使用相同分数映射；候选兜底仅供复核时不评分。

## 汇总与证据

`summarize_card_scores` 先对同卡多次事件取均值，再对可评分卡等权平均，避免多次重复的容易动作获得额外权重。原卡、视觉代理、人工三通道分别汇总，禁止混成一个总分。缺测卡不进入分数均值，但保留在适用卡覆盖率分母；另报298卡目录覆盖。无可评分卡返回空分数；无适用卡返回空覆盖率。重复事件去重，互相冲突的同卡/同视频/同事件/同人结果排除。

合成反例测试覆盖边界算术、联合帧、缺帧、错误视频、PTS矛盾、切换主体/相机、周期外动作、移动踝造成的假降髋、未知单位/算子和重复计权。公共真实视频回归另见 `real-video-validation-20261022.md` 与数值fixture。这些检查不等于298卡已自动实现，也不证明动作识别或技术评价准确率。
