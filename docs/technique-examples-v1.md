# 官方教学来源与评分卡关联 v1

`scoring-demo-web/app/lib/technique-examples.ts` 是唯一教学链接清单。2026-10-24 阅读并核验四个 USTA/LTA 原始网页后，按明确编号关联 27 张原卡、9 组观察重点。评分卡详情可展开教学链接；没有关联资料的卡不显示空面板。

这批工作提供有机构来源的学习示范，不产生优秀动作 A 级真值、训练样本、评分阈值或新增真实评分覆盖。关联表示网页讨论相关动作，不证明网页逐条满足原卡全部条件。仅链接原站，不复制视频或图片；视频起止时间尚未标注，页面中的发布时间不明时记录 null。

来源与关联边界：

- [USTA 正手准备](https://www.usta.com/en/home/improve/tips-and-instruction/national/improve-your-tennis-game--get-your-forehand-flowing.html)：2018-06-29，正文的单位转体练习，关联 GS01-M03-01。
- [LTA 反手入门](https://www.lta.org.uk/play/tennis-tips-and-techniques/how-to-hit-a-tennis-backhand/)：转身引拍、单反与双反随挥、准备姿态分别关联 GS02/GS03 对应条目，不据此判断拍面角度、精确触球时刻或发力。
- [LTA 步法教学](https://www.lta.org.uk/play/tennis-tips-and-techniques/improve-your-tennis-footwork-on-court-with-these-simple-tips/)：移动组合、短步调整、不同时间条件下的站位及回位启动。它没有给出机器评分阈值、脚部完整周期或动态战术目标，未关联 FS10 的合理目标判断和到位判定。
- [USTA 反手切削练习](https://www.usta.com/en/home/improve/tips-and-instruction/national/tennis-techniques--hitting-the-slice-backhand.html)：自抛与对练作为相关技术练习，关联 GS04-M08-01/M09-01；不为旋转、摩擦或拍面角度卡提供测量证据。

关联按完整卡号匹配，不用技术族前缀批量扩大覆盖。所有链接都来自本地维护的清单，报告内容无法插入外链。组件不修改报告，不请求网络；点击后由浏览器打开官方页面。当前来源内容经网页文字核验，未宣称逐帧观看和专家标注。

验证：教学清单测试检查唯一卡号、原始 298 卡中的存在性、官方域名，以及正式/历史报告分数不被教学入口改变；现有评分面板与导出回归继续执行。
