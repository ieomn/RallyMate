# 正手切削、接发与持拍侧实拍复核（2026-10-28，第五轮）

本轮将源画面事实、模型关节、自动阶段、人工复核和最终评分分别核对。评分曲线与聚合权重不按职业/普通标签调整；新增的是动作证据规则、手部角色绑定和投影可观测性检查。样本中的姓名和“普通 B”等是历史文件标识，不能用作实际身份、水平或持拍手的判断依据。

## Dimitrov/Tiafoe 片段的两处不同问题

本轮复用 [Dimitrov/Tiafoe 原视频](https://commons.wikimedia.org/wiki/File:2024_US_Open._Grigor_Dimitrov_vs._Frances_Tiafoe.webm)，作者 Oleg Yunakov，源页面标示 CC BY-SA 4.0。片中近场白紫球衣目标在约 13.8 秒有完整双手挥拍。第四轮所写“横向幅度约 0.024 躯干长度”应更正为**最终阶段 13.633–14.200 秒内，所选左运动腕起终点的横向净位移**；它不代表挥拍中途的运动范围。原图存在明显前挥和高位随挥。旧规则只接受水平跨身轨迹，错误拒绝了起终点回到同侧的完整弧形运动。

新增的替代证据检查连续双腕共同运动、肩部相对运动弧和动作内实际记录的球拍检测框，不重新挑选更有利的阶段，也不降低原跨身几何门槛。构造的举臂、单臂平衡、静态持拍、刚体平移/转身、断帧及跨人物反例均未通过该替代证据；不能据此宣称对所有视角和动作均无误报。角度、半径、时长等是公开的工程识别条件，不是用户资料给出的评分分档，亦不是力学或触球真值。

约 8.15 秒接发的漏检是另一条路径：模型在准备阶段将同一球拍框只关联给较近的左腕，真实右侧前挥因此缺少物体支持。准备阶段的拍柄有遮挡，原图不足以确定每一帧的实际握法。修复使用的是**双腕同时邻近唯一球拍框的模型观测**，不能称为已看清双手握柄或握拍转换。只有同人物、同参考系、连续准备范围内的共享观测，且后续有双腕分离时的独立同侧球拍观测，才可支持候选；共享观测不增加左右持拍手的独立票数，仍须至少两帧真实球拍检测。

对这条视频的复核还发现，基线已评分的约 19.567 秒和 21.383 秒并不是可确认的完整击球：前者是来球越过后的低拍收回，后者是低位持拍走动。因此不能以“保住旧评分”作为验收目标；真正应验证的是约 8.15 秒接发挥拍与 13.867 秒双手底线动作。源审计保留密集原帧、PTS 与哈希，旧自动结果不作为人工真值。

## 运动腕和持拍手

旧 `racket_hand` 实际承担“用于计算阶段的运动腕”含义，与人工复核的主持拍手混用。新结果显式区分 `motion_wrist`、`measurement_hand`、`primary_racket_hand` 及其来源；旧字段仅作标明语义的兼容别名。

经过源绑定的双手反拍可以用左腕确定阶段、右手作为已复核的主持拍手，但必须从同源实际二维观测重新计算双腕在该加速阶段的共同运动。不能仅凭“双反”标签或序列化的通过标记放行。单手动作的左右冲突仍不得套用双手例外。

六个旧冲突的独立源审计发现：四个涉及双反角色，其中 Djokovic 首窗实际仅有准备；另两条单手动作有不同原因。Sharapova 片段的 native 左右标记与原图相符，但当前自动阶段仍选择了自由平衡臂；本轮未自动纠正到真实持拍腕，已复核的单手侧冲突继续拒绝评分。普通 B 的分离姿态中，模型左腕落在实际持拍右腕、模型右腕落在自由左腕。后者属于局部姿态侧标错配，不能通过整窗交换左右或删除人工复核来修正。Djokovic 首窗从准备峰约 4.004 秒改为实际前挥峰 4.713 秒，旧人工类型绑定不自动迁移。

## 切削的新素材与测量限制

[Rick Macci 正手切削原片](https://www.youtube.com/watch?v=hSH7_FlCoI0) 在 44–64 秒包含三个自喂球动作、两个空挥示范和中间站立讲解。动作类型、手侧和阶段先按源图冻结，再运行实际 GPU 推理；五段均保留，未按评分选择样本。该机位没有足以独立确定击球前向的球场参考，故切削前下联合轨迹不能测量。五个固定人工窗的专项覆盖分别为 2/5、2/5、2/5、1/5、2/5；本轮新增正手切削实拍中，联合前下轨迹的有效测量仍为零。

[WTA 官方实战切削](https://www.wtatennis.com/videos/1374603/2019-acapulco-shot-of-the-day-stephens-wicked-forehand-slice) 的原速动作约在 20.8–21.76 秒，目标是远端球员。后面的慢动作回放不作为第二次独立动作，也不用于真实速度或时序。默认流程在 68 帧均未建立运动员身份，未产生 native。另一个明确标记为人工选人的实际推理得到 67 帧远端目标姿态；21.28 秒真实目标漏检仍保留为空，其后产生新 epoch。完整冻结窗口跨 epoch，验证器拒绝拼接，不能缩窗凑出完整动作。此实验不计自动选人成功；远端人物约 55 像素高、部分检测框未包住伸展手臂，也是明确的测量限制。

WTA 机位还暴露了切削指标的投影退化问题：独立球场前向几乎与画面向下重合，旧公式可能把同一单轴位移同时计作“前”和“下”。新增检查将两个单位方向组成的基底条件数限制在 4 以内；这是发现投影问题后、实现前声明并冻结的数值误差放大界限，不是按样本分数标定的运动学阈值。超界时保留单轴诊断，但联合切削要求记为缺测。良好条件下的原有分数公式保持不变。该检查不把二维投影提升为真实三维路径或受力测量。

## 与用户资料的对应

资料的固定提取与定位保存在 `contracts/scoring-reference-20261004.json`。本轮直接核对了双手共同控制、共同加速和随挥连续（VIS-GS P0127、P0145、P0154），以及正手切削“高位→前下方”（VIS-GS P0283）。资料同时要求真实触球有球/拍轨迹支持；二维双腕共动不能替代触球或真实受力证据。

接发资料 VIS-RT P0036 强调来球越快可用准备时间越短，不能只套固定绝对幅度。当前没有可信的来球速度与压力标尺时，这部分仍标缺测，不把普通底线动作改名为接发后宣称完整验证。

同一 Dimitrov/Tiafoe 原片本轮增加了对手实际姿态推理。远端发球阶段已被检测到，但符合当前轨迹长度条件的候选球轨迹 ID 64，首点在 8.000 秒，距发球峰 483 ms，已超过原有 450 ms 接续范围；球迹没有覆盖发球人附近及足够长的两人间路径。因此剩余自动接发类型缺口是球关联链不足，不是没有对手姿态。没有把 450 ms 门槛放宽成刚好通过这段素材。

独立人工接发窗保持原 7650/8100/8220/8750 ms 阶段、右手、对手两帧、来球三点及方向证据不变，在新 native 上重新验证为 **4/8**：准备配合、阶段连续性、中心前移、向前挥出。髋肩峰均在 8100 ms，时序仍不可分辨。这个结果不计自动接发判型命中。

本轮实际推理、人工窗与自动回放分别留证。四次隔离验证捕获（Dimitrov 对手上下文、Rick、WTA 默认及 WTA 人工选人）共保存 2,365 条成功 native：Dimitrov 对手上下文 1,798、Rick 500、WTA 默认 0、WTA 手选 67；不同人物不合并评分，WTA 手选不计自动选人成功。捕获源码为固定 `a003456`，最终 v3 在这些不可变产物上重放。这个数量不含后续两次正式整段上传；它们属于同源服务验证，不增加独立视频数。
