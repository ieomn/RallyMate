# RallyMate 前端产品改版

本轮按“深色、克制、突出视频与训练表现”的用户选择完成界面及使用流程重构。采用深炭色、柠檬绿强调、统一图标和卡片层级；球场插画与图标均为项目内 SVG，不依赖外部图库、字体服务或新模型。

## 页面与流程

- **训练总览**：品牌球场插画、新建分析、真实最近记录、分析进行中入口。
- **训练记录**：缩略图、名称搜索、查看时间排序、空状态与无匹配状态、报告导入。仅显示此浏览器实际保留的最近记录，最多 12 条；不展示虚构训练量、评分趋势或账户。
- **视频分析**：拖入或选择文件、移除与重选、上传及处理进度、失败重试、原视频回放、片段定位、测量详情、训练问答和报告导出。
- **拍摄指南**：可展开的拍摄说明、个人检查清单、分析入口。清单不会阻止上传。

桌面使用固定侧栏，手机使用底部导航。所有主导航、列表、搜索和播放器接入实际状态；原来的离线演示评分界面退出主产品。

## 回放调整

人体骨架和球路默认关闭，集中在折叠的“分析工具”中。播放器提供播放／暂停、拖动时间线、当前时间／总时长、0.5／0.75／1／1.5／2 倍速和浏览器全屏功能。不支持全屏时禁用相应按钮；媒体播放或全屏请求被拒绝时显示原因。既有姿态时间安全检查与坐标规则保留。

报告首先显示视频和复盘重点，测量证据参考分作为次要的折叠说明。参考分、候选动作、二维测量与正式技术评分的含义没有被界面改版改变。

## 状态与兼容

显式页面选择优先于旧任务存储。进入首页不会自动打开上一次任务；旧 `?job=...` 链接仍打开报告。浏览器前进／后退跟随页面地址；正在运行的任务可以在导航后继续读取，完成时不抢走当前页面。任务切换与异步文件导入使用独立运行编号，过期响应不能覆盖新任务。

包含结果的 JSON 备份优先本地导入，不因页面切换偷偷改成线上任务。备份不附带原视频时明确显示视频缺失，测量数据仍可阅读。报告导入导出、同源媒体代理、后端鉴权和既有任务接口保留。

## 后续修复：返回首页、信息密度与长视频等待

2026-10-04 的后续验收增加以下修复：

- 工作台四个页面统一保留“返回首页”，桌面品牌标志也链接 `/welcome`。采用原生链接避开当前 vinext 生产客户端路由错误；页内工作区切换沿用状态导航。分析期间仍可返回首页，后台任务继续运行。
- 删除“专注每一次进步”、装饰性英文标签、重复说明和无功能编号；必要正文、状态和控制标签统一提高到至少 14 px。宣传页与工作台同时调整，保留演示性质、测量边界和错误提示。
- 原先逐帧推理占进度的 3–96%，结束后事件、特征、评分和导出没有连续回调，因此界面长期显示约 95%。现在逐帧阶段占 3–85%，后续按回放、人物轨迹、动作识别、事件、特征、评分、写入、报告和校验分别反馈；特征与评分阶段显示实际完成数量。只有任务真正成功才显示 100%。
- 前端根据真实阶段显示状态、完成数量和用时；一分钟没有收到新进度时明确提示。完成任务的用时以完成时间截止，不因重新打开报告而继续累加。
- 后端复用每个连续序列的相位信号，批量执行同一平滑与求导公式，避免每条特征深拷贝整段视频元数据，并逐行写入大产物。模型、逐帧采样、测量定义及评分授权规则保持原配置。

### 性能与一致性验证

本机 RTX 5070 Ti、RTMPose 环境、4 个 CPU 线程；使用同一条约 479.8 秒、11,516 帧的实际任务产物：

- 原任务记录的评分后处理组合耗时 604.686 秒，包含评分循环之外的 portfolio、readiness 和 HTML 报告。优化后的完整 `run_minimum_scoring_loop` 为 56.174 秒；两者计时边界不同，不用于宣称同口径加速倍数。
- 精确同口径的前 12 个事件、224 项特征计算由 14.108 秒降至 0.614 秒；2,687,866 个数值字段和非数值字段全部一致。该倍数只适用于这组后处理计算。
- 完整重放生成 636 个事件、12,720 条特征、2,756 条指标和 2,756 条评分；逐行完整 JSON 与原产物一致。
- 新服务通过真实 HTTP 上传、GPU worker、报告和姿态回放的端到端验证：前 10 秒、240 帧，pipeline 用时 13.285 秒，其中检测 2.896 秒、姿态 3.798 秒、评分后处理 0.696 秒；最终成功且进度达到 100%。完整 8 分钟视频没有重新跑全套 GPU 推理，不将局部提速等同于整体提速。
- 前端 177 项回归通过，生产构建、类型检查和静态检查通过；后端 161 项相关数值与语义回归通过，新增阶段进度及调用兼容测试通过。浏览器验收桌面、390 px 与 320 px 窄屏导航，无横向溢出，原任务报告可以读取。
