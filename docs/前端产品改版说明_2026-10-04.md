# RallyMate 前端产品改版

本轮按“深色、克制、突出视频与训练表现”的用户选择完成界面及使用流程重构。采用深炭色、柠檬绿强调、统一图标和卡片层级；球场插画与图标均为项目内 SVG，不依赖外部图库、字体服务或新模型。

## 页面与流程

- **训练总览**：品牌球场插画、新建分析、真实最近记录、分析进行中入口。
- **训练记录**：缩略图、名称搜索、查看时间排序、空状态与无匹配状态、报告导入。仅显示此浏览器实际保留的最近记录，最多 12 条；不展示虚构训练量、评分趋势或账户。
- **视频分析**：拖入或选择文件、移除与重选、上传及处理进度、失败重试、原视频回放、片段定位、测量详情、训练问答和报告导出。
- **拍摄指南**：可展开的拍摄说明、个人检查清单、分析入口。清单不会阻止上传。

桌面使用固定侧栏，手机使用底部导航。所有主导航、列表、搜索和播放器接入实际状态；原来的离线演示评分界面退出主产品。

## 回放调整

人体骨架和球路默认关闭，集中在折叠的“分析工具”中。播放器提供播放／暂停、拖动时间线、当前时间／总时长、0.5／0.75／1／1.5／2 倍速和浏览器全屏功能。不支持全屏时禁用相应按钮；媒体播放或全屏请求被拒绝时显示原因。既有姿态时间安全检查与坐标规则保留。

报告首先显示视频和复盘重点，测量证据参考分作为次要的折叠说明。参考分、候选动作、二维测量与正式技术评分的含义没有被界面改版改变。

## 状态与兼容

显式页面选择优先于旧任务存储。进入首页不会自动打开上一次任务；旧 `?job=...` 链接仍打开报告。浏览器前进／后退跟随页面地址；正在运行的任务可以在导航后继续读取，完成时不抢走当前页面。任务切换与异步文件导入使用独立运行编号，过期响应不能覆盖新任务。

包含结果的 JSON 备份优先本地导入，不因页面切换偷偷改成线上任务。备份不附带原视频时明确显示视频缺失，测量数据仍可阅读。报告导入导出、同源媒体代理、后端鉴权和既有任务接口保留。

## 验证记录

- 前端生产构建、类型检查和静态检查通过；172 项前端测试通过。后端推理与测量代码本轮未修改。
- 一段已有真实视频经新版浏览器上传，48.066 秒、1,441 帧，在约 60.6 秒后成功完成分析。上传、处理进度与报告显示均经过实际操作；浏览拍摄指南时任务正常继续。
- 实测记录搜索的匹配／无结果状态、排序、指南展开与清单勾选、页面前进／后退、手机底部导航、回放拖动与半速播放、干净默认画面。
- 实际下载 HTML（136,595 字节）和 JSON 备份（4,833,494 字节），再通过前端导入该备份并导航返回，测量结果保持可读。
- 390×844 手机视口与桌面布局无横向溢出。测试视频、导出备份和界面截图保留在本机，不进入 Git。

前端继续使用现有分析服务与当前浏览器历史机制。本次未引入账户、支付或云端跨设备历史系统；正式技术评分仍等待教练标注标定。新版界面的完整性不构成模型准确率或公开商业部署完成的声明。
