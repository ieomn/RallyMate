# 手腕二维运动计算修正

`time-weighted-vector-kinematics-v1.0.0` 修正两个可复现的数学问题：逐坐标中值滤波随图像坐标轴旋转改变轨迹，以及阶段识别和过程测量在相同输入窗口上使用不同滤波与速度公式。它没有改变网球动作阈值，也没有引入三维角度或技术等级。

输入仍是已经通过原姿态和来源检查、以躯干长度归一化的二维点。时间使用每个真实观测的 `Sample.time` 毫秒值，不从帧率推算；现有源若将时间舍入到毫秒，精度仍受这个记录限制。本批不改原 PTS 或来源绑定。相机、选人、归一化基准变化继续由原连续性规则切断；缺点、时间不递增、超过 160 ms 或局部中位观测间隔 1.8 倍的间断，以及对应源帧步长异常均不跨越。源帧步长来自已采样序列的观测节奏，不声称所有视频解码帧都已进入姿态分析。

每个连续段首尾保留原点。内部点用前后各 80 ms 的三角时间权重做局部线性拟合，左右至少各有一个点且总数至少三个。相同标量系数作用于整个向量，因此图像坐标旋转、平移和统一缩放与滤波可交换。这个固定带宽是工程平滑设置，在真实新结果计算前冻结，不是根据某个动作得分挑选的阈值。它会衰减尖锐变化，且首尾没有相同降噪效果；不能把平滑后的峰值当作真实瞬时速度。

速度定义为相邻滤波点之差除以这两点实际时间差（秒），取向量长度。时间位置是两帧时间中点；它是区间平均二维速度，不是中心帧瞬时导数。阶段规则仍需要原帧锚点，因此将区间速度关联至结束帧，第一帧复用首个实测区间速度，不填人为零。锚点因此带有不超过相邻观测间隔的离散时间分辨率。不同阶段窗口独立滤波，不能要求不同窗口的端点结果相同；相同窗口的两入口现在完全一致。

`stroke_analysis` 在阶段边界确定后，对最终报告窗口重新计算，不再切取含窗外点影响的滤波序列。`ANALYSIS_VERSION` 升为 `stroke-motion-analysis-v2.5.1`，使 `summary_with_actions` 从原帧重新分析旧缓存。规则后端版本为 `2.1.0`；过程报告外层 `process-motion-v1.1.0` 保持前端兼容，新增 `wrist_kinematics` 记录算法版本和测量含义。此次没有更改候选检测器自身的独立滤波，也没有更改投影角度、逐帧躯干尺度或相对分聚合。

候选上下文、独立连续段和最终报告窗可能具有不同的局部中位采样间隔。`2.5.1` 保留各窗口原有间隔门槛：若后续窗口暴露缺帧或不连续手腕观测，以专用 `WristKinematicsUnavailable` 取消这一候选，并在已有动作类别说明中记录跳过数量；其余有效动作继续分析。规则后端入口、外部后端回退规则入口和最终窗口重算均采用这一处理。不会跨间断求速度，也不把无测量填成零；其他 `ValueError` 或编程错误不因此吞掉。向量算法和数值阈值版本保持不变。

真实回归取自用户视频 `IMG_5709.mov`，run `b10f614f-b1c1-4207-b9d4-50082eb43164` 的既有帧 690–717。冻结的原二维轨迹绕坐标轴旋转 45°，旧峰值由 11.4996158 变成 10.6530912 躯干长度/秒（约下降 7.36%），几何运动没有变化。新回归要求逐区间速度在旋转和平移后数值一致，并要求过程与阶段两入口使用相同滤波轨迹。该来源只证明数学不变性，不是姿态或技术动作真值；同一 SAM 三维模型角度与二维投影的差异留作独立问题，未混入本修正。

专项还覆盖非均匀时间的匀速与二次曲线、缺点和身份断点、缩放后归一化、噪声及未平滑端点。实际两视频完整重新识别由独立重放保存新结果，原 summary 和交付缓存不覆盖。
