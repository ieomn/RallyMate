# 逐卡规则与计算核心独立审查（2026-10-22）

审查范围是298卡目录、构建脚本、读取接口、规则文档，以及 `card_kinematics.py`、`card_evaluation.py` 和对应测试。本次重点是原文到计算条件的语义链，不把测试通过等同于所有卡或视频验证完成。

## 五张复杂卡的追踪结果

1. **GS01-M03-04，重心加载至持拍侧**：原文要求特定侧别与加载；早期代理只检查任意方向髋位移和躯干角变化，方向相反也可能通过。已取消该代理判级，改为需持拍侧、支撑脚和髋相对支撑证据的复核；原有位移作为附属观察保留。真实承重仍不可从单目直接测量。
2. **GS01-M06-03，持拍手进入准备加速姿态**：原文M06结束标志才是持拍手开始主动加速，早期关键词映射用实际腕加速评价准备姿态，存在阶段错配。已取消该代理判级，要求持拍侧肘腕姿态、球拍状态及正确阶段证据；M07腕加速规则不受影响。
3. **GS03-M04-01，主动蹬地**：原文是下肢主动发力，并未要求双膝同时伸展。早期两膝同时伸展条件会不合理压低单腿支撑技术。已将此卡和同类GS01/GS02蹬地卡改为先确认支撑侧再复核，不把双膝角度当主动受力证据。角度观察仍保留。
4. **GS03-M08-01，单手稳定击球**：原卡依赖手臂、球拍、活动球与接触时序；早期稳定关键词映射只得到髋投影与躯干稳定，不能证明单手控制或真实击球。此卡与GS02-M08-01双手稳定击球均改为接触及手拍控制证据复核，身体平衡仅作为附属观察。不能用无球空挥的稳定姿态给该击球卡等级。
5. **FS03-M03，移动脚完成交叉跨步**：规则用完整连续步周期内投影换序和躯干归一化位移，避免两帧端点弦交叉直接判定。原文还涉及移动轴、轨迹交叉、步幅/髋宽及稳定性，现有两个条件没有完整覆盖。保留明确局部视觉代理，补充逐项未覆盖说明；不称完整原卡交叉步评分。计算核心的步周期必须与评分窗口一致，不能绑定一个子周期却用整事件末端算位移。

第一轮因此取消7卡不恰当代理判级。降低错误的可评分计数是语义修复，不表示减少已通过真实视频验证的覆盖；这些规格本来就没有被声明为已验证。

第二轮逐家族检查另外纠正12卡：GS01-M04-06、GS01-M05-06、GS03-M05-05的准备骨盆/胸廓启动改为专项准备姿态复核；GS04/05-M04-02、M05-04保持侧身改为有参考方向的姿态复核，不能以不断转动为正确；FS05-M03/M04微调改为需目标与小步幅边界的复核。以上9卡不再凭错误条件评分。GS01-M05-05维持肩髋分离改为投影分离均值≥5°且范围≤15°，明确为未标定的二维存在与维持代理；FS06/07-M05保持准备改为静态支撑投影与躯干稳定，不强制再次减速。

第三轮区分持续姿态与动作变化：GS03/04/05的6张M07/M09“自然张开”改为双腕距离中位数≥0.8躯干长度及局部平衡，已展开的姿态不再被要求继续张开；M06离拍仍检查双腕分离变化。5张M01降低重心卡须关联真实预加载局部子窗，整阶段首尾恢复到原高不能判未下压，因此暂改专项复核，明确 `temporal_preload_subwindow_required`、同人同视频与GS阶段内包含关系；不能复制FS01-M02评分或靠局部髋下降候选直接评分。

当前最终目录为158张视觉代理规格、140张专项证据/人工复核，40项测量定义。目录数量仍不等于已实现或已验证数量。

## 原文冲突和阶段修订复查

三张冲突卡按原始完整字段重新检查。发现GS02-M01-01/02的“原文关键项”也相互错配，不能只修定义。已在 `effective` 和修订记录同时更新关键项与可评价状态，并保留原始关键项在 `source.fields`。名称、ID和原文段落定位未改；识别点、计算、所需点、不可评价、定性等级与反馈使用一致语义。GS01-M10-04也补全恢复准备的关键项和工程状态。

20个缺边界阶段分别沿双反、单反和切削的阶段语义修订。双反包含双腕共同加速及双手随挥；单反包含辅助拍喉解除、单手加速和展开收拍；切削M02截至已有M03首次转肩。GS04-M02重复M03定义的修复依据其本身五张移动卡及复用GS03-M02关系。资料支持见 [USTA双反说明](https://www.usta.com/en/home/improve/tips-and-instruction/national/improve-your-tennis-game--the-driving-force-in-your-two-handed-b.html)、[USTA单反说明](https://www.usta.com/en/home/improve/tips-and-instruction/national/improve-your-tennis-game--hitting-a-one-handed-backhand.html)、[LTA反手指导](https://www.lta.org.uk/play/tennis-tips-and-techniques/how-to-hit-a-tennis-backhand)。这些资料不能证明本项目的具体阈值或十阶段精确时刻，目录均标记工程解释与待视频边界验证。
