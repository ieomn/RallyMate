# 原始298卡执行契约与原文修订 v1

本版本建立298张原卡的可追溯执行契约，其中158张定义视觉代理条件，140张要求额外证据与人工复核。**目录数量不是已实现、已接线或真实视频已验证数量。原始卡完整自动A–E判级仍不得由该目录宣称完成。** 运行时只能评价已注册提取器实际算出的同窗指标，真实视频覆盖必须另外统计。独立语义复核取消了21张卡不恰当的代理判级，保留其局部观察，并纠正9张卡的维持状态条件，见 `card-rule-review-v1.md`。

## 原文与修订

输入固定为 `contracts/scoring-reference-20261004.json` 与 `src/rallymate_scoring/data/technical_review_rules.json`。输出记录两份输入SHA256，以及每卡原Word文档SHA256、表格号、逐字段段落定位、原始文本和原始等级。原文文件与原快照没有被覆盖。

`scripts/build_card_rule_catalog.py` 确定性生成 `src/rallymate_scoring/data/card_rules_v1.json`；`card_rule_catalog.py` 提供 `load_card_rules()`、`get_card_rule(indicator_id)`、`get_stage_rule(stage_code)` 和只统计契约的 `catalogue_coverage()`。返回对象为深拷贝，不能污染进程内缓存。

24条修订包括：

- GS01-M10-04：原技术定义误混入“GS-02 双手反手”标题。依据本阶段恢复准备定义重写技术含义、观察点、计算、所需点、不可评价及反馈，原文保留在 `source`。
- GS02-M01-01、02：保留ID和名称，将01明确为观察来球，将02明确为双手握拍。计算、依赖、不可评价、反馈与定性等级一起纠正，不只交换标题。真实注视不能由头朝向确认，握拍不能由双腕接近确认。
- 20个缺边界阶段：GS02-M03至M10、GS03-M01至M10、GS04-M01至M02，共影响97卡。根据各技术自身定义补齐可复核起止标志，并显式标记为工程修订、待视频标志验证。双反保留双手共同加速与随挥；单反明确辅助拍喉、双手分离、单手加速及展开收拍；切削M02接续已有M03首次转肩标志。没有复制正手十阶段。
- GS04-M02：发现其阶段定义与M03转肩重复，和M02第一步、调整、身体移动五卡不一致。修订为垫步后的移动调整，截止首次切削转肩；原定义保留。

这些技术解释参考已读取的 [USTA双反说明](https://www.usta.com/en/home/improve/tips-and-instruction/national/improve-your-tennis-game--the-driving-force-in-your-two-handed-b.html)、[USTA单反说明](https://www.usta.com/en/home/improve/tips-and-instruction/national/improve-your-tennis-game--hitting-a-one-handed-backhand.html) 和 [LTA反手指导](https://www.lta.org.uk/play/tennis-tips-and-techniques/how-to-hit-a-tennis-backhand)。资料分别支持双手角色、单反身前触球及准备—定位—击球—随挥—恢复的技术语义。**资料不提供本项目数值阈值，也不证明十阶段必须互斥、等长或依次完全分开。** 允许有生物力学重叠的阶段，必须分别给出实际起止证据。

## 指标、质量与证据

目录中的40个指标各有单位、数学定义、依赖关节、相机要求与外部依赖。每卡联合条件明确列出 `metric/operator/value` 或 `bounds`，没有“动作优秀所以全卡A”的输入。相同条件不得重复计权。

关节集合按计算需要确定。例如投影支撑比例只需双髋与双踝；双腕距离需双腕和归一化用的肩髋，不额外要求肘或耳可见。原卡要求的原始关键点编码仍单独保留。卡片自己的共同有效帧需达到70%，分母为封闭卡窗内全部预期源帧，漏帧和遮挡保留在分母。归一化坐标有限、明确观测置信度不低于0.35是工程检查；0.35不是原Word数值。坐标是否位于原图之内须由源几何掩码另证，当前通用core的归一化坐标不能单独证明这一点。模型生成坐标只证明几何可用，不证明真实可见。

每窗必须绑定视频SHA256、球员ID、选择时期、相机参考时期和严格递增源帧/真实时间戳。换人、遮挡或时间断裂不得通过拼接两端消除。位移和速度必须使用稳定或补偿的相机参考。场地前后、球路方向、握拍接触、足底接触、真实视线、力、能量与球自转不能从相关二维几何中补造。

GS必须绑定具体原卡阶段标志。估计准备/加速/随挥三段不能重命名为十阶段。阶段边界缺失、片段截断、所需专项跟踪缺失或指标提取器尚未注册时，保留局部观察并给出不可评价/人工复核原因。

FS01-M02/M05及FS09-M03/M04/M05使用 `temporal-card-evidence-v1.0.0` 的连续子窗联合规则。FS01-M02要求髋下降、双膝变化在同窗发生；FS09-M03增加减速、髋下降、双膝屈曲共同发生的时间比例，避免不同时间的端点变化拼成吸收惯性。低踝速度仍不代表真实支撑。局部髋下降兜底只能输出待复核候选；站立调整脚跟也可产生这种模式，未验证动作类型时不得评分。

## 阈值与分数

现有数值均是v1工程代理检查，尚未通过教练标注样本标定。4°膝角变化、0.03躯干髋下降、0.15躯干位移等用于排除微小变化；它们不是普适好动作阈值。范围与稳定性检查可能受机位、透视与个体差异影响，运行输出必须带版本和限制。尚未验证的阈值不能提升为原卡自动等级。

所有必要条件都具有有效测量且通过联合质量门槛后，才计算代理条件完成率 `r = 成立条件数 / 必要条件数`：全部成立为A；`r≥0.75`为B；`r≥0.5`为C；`0<r<0.5`为D；充分可见证据下全部条件不成立为E。对应100/80/60/40/20，只表示本卡工程代理条件完成度。单条件代理只能得到A或E，并不暗示已评出五级技术水平。

缺测不是条件不成立，缺测不会得到E或零分。原文等级、视觉代理评分、人工评分与不可评价分别输出。默认汇总先在同卡内平均多次有效事件，再对可用卡等权平均；缺卡从分数分母排除，但保留在适用卡覆盖率分母，无可用卡时总分为null。等权和等级点值是工程选择，原Word没有提供这些聚合权重。

## 验证边界

`tests/test_card_rule_catalog.py` 检查298原卡与原字段逐项保真、20阶段/97卡修订范围、三项冲突关联字段同步、条件数学类型与关节集合、重复条件、缺测策略、确定性重建及缓存隔离。该测试证明执行契约的一致性，不能证明识别准确率、158卡全部已有提取器或真实视频已通过。各卡 `validation.video_evidence` 当前为空，待实际运行证据填写；严禁仅凭该目录将目标标为完成。
