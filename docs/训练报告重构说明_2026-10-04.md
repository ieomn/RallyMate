# 训练报告与时序识别重构

开发分支：`codex/scoring-report-rebuild`。恢复基线：`60457524bcd828ad0a9063c5e4af0c67089f18ad`。

## 本次结构

实际链路为视频/真实时间 → 连续主体与相机参考 → 动作候选 → 可替换时序识别 → 对应阶段测量 → 证据参考评价 → 可定位回放的复核建议。

- `temporal_recognition.py`：统一 Halpe26 关节顺序、固定时间网格、原始观测时间、缺测掩码、关节置信度、主体/相机/归一化片段身份。默认后端为明确标注的规则基线；后端可替换且输出经过阶段/时间/分类契约验证。
- `stroke_candidates.py` / `stroke_analysis.py`：在候选所在连续片段内判断持拍手，肘部缺测不再删除可观测的手腕运动。动作类别未知时仍保留可测维度。候选与运动峰值均不表示确认触球。
- `rotation_analysis.py`：保留原整段至少 7 个观测、200 ms、采样与时间覆盖均至少 80% 的摘要门槛。另输出严格连续的局部窗口及按阶段计算的测量；局部结果不替代整段摘要。肩线、髋线和夹角分别降级，镜头参考或归一化基准变化时断段。
- `footwork_review.py`：保留原整组状态和评分质量门槛，新增逐特征的值、单位、关节要求、原因、时间窗和来源版本。同组缺测不再掩盖其他有效特征；独立目标方向仍须独立来源。
- `analysis_report.py`：汇总分层状态与复核/补录建议；建议绑定实际测量和回放窗口。参考分仍由原证据公式产生，技术分与正式等级为空。新增局部观测不偷偷加入旧参考分。
- 前端：训练报告首页展示回放、测量证据参考分、重点复核建议；时间线定位动作与步伐，细节默认折叠。保留上传、进度、重试、历史、报告导入及 Markdown/HTML/JSON 导出。

## 开源流程选用与边界

本轮是自行实现的接口和流程，未复制第三方源代码、导入数据集或安装新的神经网络依赖。原 RTMPose 环境继续使用。

| 来源 | 已采用的设计 | 未宣称的能力 |
| --- | --- | --- |
| [MMAction2](https://github.com/open-mmlab/mmaction2)、[骨架输入文档](https://mmaction2.readthedocs.io/en/latest/dataset_zoo/skeleton.html) | 时序后端可替换，明确 M,T,V,C 输入与关节/时间/掩码契约 | 通用预训练权重不等于网球专项分类器；本轮未训练或接入此类权重 |
| [FineDiving](https://github.com/xujinglin/FineDiving) | 在对应动作阶段内测量并保留阶段不完整状态 | 未使用跳水质量预测权重或数据，阶段仍由规则估计 |
| [Fitness-AQA](https://github.com/ParitoshParmar/Fitness-AQA) | 将建议拆成具体观察依据、适用条件和复核目标 | 无教练真值时不把测量缺失或低分改名为技术错误 |

未来可评估 CoRe 的标注参考动作比较，但需先核验代码与数据许可，并准备独立教练标注。本轮球路关联的跨 ID 300 ms / 方向余弦 0.7 约束保持原样。

## 教练标注对接

用户已确认可以安排教练标注一批视频。先使用一小批覆盖正面/背面/侧面/斜角、横竖屏、人物大小和遮挡情况的视频统一标注口径，再扩展数量。

1. 每条标注绑定原视频哈希、原始毫秒区间、球员身份、拍摄视角与可见性；同一球员、同一拍摄场次、同一原片的裁剪须在数据切分时保持同组。
2. 动作类型：正手、单反、双反、发球、其他、无法判断；记录持拍手和判断依据。无法判断保留为空，不能按算法候选强填。
3. 阶段：按视频标出准备、加速挥拍、随挥的起止边界，并标记裁剪、遮挡、缺阶段。真实触球只有直接可见或独立证据支持才单独标注。
4. 步伐：单独记录准备/启动/制动/恢复、相关脚部可见性、可观察问题及证据区间。二维脚运动不当作实际接触地面或受力真值。
5. 转体：分别记录肩髋可见性、二维观察与教练技术判断。单机位二维角度不作为三维轴向转体真值。
6. 技术评价：由教练先定义各动作、各错误的评价规则与适用视角，再给技术判断。保留“无法评价”、标注者身份、独立二次标注和分歧处理；算法置信度及参考分不作为教练答案。
7. 将标注接入现有校准/独立测试流程，分别报告候选检出、动作分类、阶段时间误差、逐项可测率与技术评分一致性。技术分需要独立测试，不能在同一批拟合样本上宣布有效。

## 验证解释

合成不变性和回归测试验证边界处理、计算与接口一致性。本机视频重跑验证完整链路及可观测项变化；没有独立教练真值的样本不能用于宣称识别准确率或评分有效性。历史报告的旧注册表绑定继续严格校验，旧产物不改写。
