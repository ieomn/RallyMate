# FS03 / FS04 连续步周期观察 v1

入口 `compute_footwork_cycle_card_evidence(sequence, event, *, events, primary_timeline, context, cycle_binding)` 为一个 FS03 或 FS04 候选窗口返回对应的 5 张卡。一个 run 可复用同一 `PoseSequence` 和 `SourceAlignedContext`；每个窗口的同组关节原始轨迹只计算一次。目录中的 FS03 是交叉步，FS04 是并步。

本模块保留目录既有的阈值与单位，不输出原文等级、代理等级或分数。两张 M01 方向判断卡需要来球/目标外部证据，始终复核。其余卡最多输出 `measured_visual_proxy` 和逐条件原始数值；这表示列出的二维代理条件可计算，不表示原文完整技术动作、专家标签或实际地面支撑已经证实。

## 显式窗口绑定

`cycle_binding` 必须含 `method="manual_anchor"`、非空 `version` 和 `evidence_reference`，以及与事件和源帧一致的 `event_id`、`video_id`、`video_sha256`、`primary_player_id`、`start_source_frame`、`end_source_frame`。目前没有注册的自动步周期检测器；调用方自称 `versioned_detector` 或提供 `complete=true` 不能授权计算结果。人工锚点明确保留为非专家候选窗口，不能证明触地、受力或网球技术质量。

严格复用已发布的时序门槛：每帧选择身份、同一视频散列和选择/相机 epoch、真实解码 PTS、连续源帧、稳定或补偿相机参考、每卡同窗所需关节联合有效比。保留全部源帧分母；连续轨迹中任一所需关节缺失不能插值通过。躯干固定尺度必须至少占原图 12 像素。端点使用首尾 20% 的中位数且各至少 3 帧，窗口少于 7 帧不能计算动态端点量；速度端点沿用通用计算器相同的样本数量。

## 周期与换序证据

每只踝的完整视觉运动周期必须包含连续低运动段、运动段和后续低运动段，各至少 80 ms；运动阈值沿用已有 0.5 躯干长度/秒，横向位移至少跨过目录既有的 0.08 躯干长度噪声带。阈值只是工程可辨识门槛，没有根据本轮 heldout 标签调整。低运动不等于足底触地或真实支撑。

左右踝顺序需在 ±0.08 固定躯干长度之外持续可分辨至少 80 ms，且窗口首尾均属于这样完整可分辨的段。每次换序还须有实际采样的近零内部点，并发生在一个已完整观察的踝运动周期内。短暂反序不能被过滤为“未换序”；没有被相反稳定脚序包夹的不确定带也不能计作 0。静态交叉、两端点弦交叉、跨缺帧连接、另一个时间段的完整迈步均不能补足换序证据。无法分辨时计数为 null，不是 0。

FS04-M04 额外要求两侧踝各有完整运动周期、前脚先迈出、另一脚随后沿同一横向方向移动，且该先后脚时段内踝距实际先扩宽再收窄。同时平移、只跟随脚移动、预先站宽后收脚都不能满足这一完整周期门槛。所有量采用同一固定相机参考和窗口内固定躯干尺度。

关节跳点/换侧诊断只有在完整具名证据证明不涉及本卡所需关节时才能忽略。原始 flags、相关 flags、忽略理由和所有复核原因均导出。该局部策略不随旧生产评分策略的全局放宽改变。

## 真实视频回归范围

`tests/fixtures/footwork-cycle-real-usta-v1.json` 保留 USTA heldout 视频首个人工回位候选的 36 帧原始二维轨迹、原始选择记录、独立核验的实际 PTS 账本子集，以及显式工程派生的选择器连续段。未改关节坐标，没有媒体或预先保存的分数。原始输入缺少时钟身份绑定，测试要求复核；加入有来源的 PTS/epoch 后可以计算连续数值，但仍未观察到满足全部门槛的完整周期。

完整 heldout 回放将 6 个人工回位候选分别投影到 FS03 / FS04 规则，共 60 个实例。原样输入为 60 个复核、0 个数值实例；明确补入解码账本和工程选择段后为 60 个有原始数值但仍需复核的实例、0 个分数。两种规则投影不是两种动作的人工真值，也不构成真实正例检测准确率。后续需独立、清晰的完整并步/交叉步正例才能验证可用覆盖率。

未跟踪的完整报告和模块/输入散列清单位于 `.codex_tmp/card-video-extension-20261022/cycle-evidence/`。人工 split-step 独立复核另存同根目录 `footwork-independent-review.json`，不用于调节新周期阈值。
