# 德约参考动作与真实视频评分对照

本轮将德约参考视频纳入评分重构验收：读取三份原视频并检查源文件，逐帧复核动作类别，使用当前分支重新计算已保存的原生姿态，再通过实际评分接口复算对照结果。三份视频共 9,162 帧，产生 46 个评分动作记录；原生推理产物复用，评分、参考比较与接口调用均重新执行。

## 来源与样本选择

参考原片为 [2012 US Open Djokovic point](https://commons.wikimedia.org/wiki/File:2012_US_Open_Djokovic_point.webm)，发布者 JC（demiace），许可 CC BY-SA 2.0。本地 MP4 由原片转码，未改变时序或裁剪。视频为 1280×720、23.976 帧/秒，共 469 帧；SHA-256 为 `80f91cb924c32026754031b24730b3888c33bd0078dbc3ec3a432f836a86be68`。德约身份依据素材来源登记，画面复核检查的是前景球员与动作的连续性。

测试视频选取 FULL-TEST 中的 c235 和 c248，共 8,693 帧。fbf52 与 c235 的动作 ID、时间和测量重复，不增加独立来源数。复核者查看原视频联系表与扩展时间窗时未读取分数；主开发者此前已看过这些数据，因此本轮是既有样本回归与参考对照。

三次测试正手与一次参考正手均可见准备、前挥和随挥。测试动作呈短引拍和前推式短随挥，参考动作包含更明显的侧转、宽弧挥出与跨体收拍。机位分别为室外日间、室外夜间斜拍和室内正面。比较范围是底线正手大类的可见关节运动。

源帧复核、接受与排除记录见 `evidence/djokovic-comparison-20261112/source-review.json`；全部配对选择见同目录 `pairs.json`。每条复核绑定视频 SHA、动作 ID、原时间窗、人物和相机时期，复核结论不修改原始评分记录。

## 实测结果

德约完整视频的当前动作分为 **93.11**，包含三次双反、一次正手和一次反手切削。用于正手比较的参考动作位于 **7.090–7.799 秒**，动作分为 **95.83**。

| 测试动作 | 原动作分 | 与德约正手的参考匹配分 | 共同测量覆盖 |
| --- | ---: | ---: | ---: |
| 夜间视频，76.467–77.267 秒 | 98.54 | 79.42 | 100% |
| 室内视频，60.233–60.833 秒 | 62.61 | 61.74 | 100% |
| 室内视频，67.333–68.167 秒 | 69.15 | 61.47 | 100% |

夜间测试正手的原动作分高于参考正手 2.71 分，而参考匹配分为 79.42。原规则中的满分平台解释了这种差异：此前 FULL-TEST 的 278 个动作记录中，下肢蓄势参与 268 项满分；准备站距 272 个可测记录中有 268 项满分；恢复控制 272 个可测记录中有 265 项满分。膝屈曲达到 15°、站距达到一个髋宽即可进入对应满分平台，这些分数主要表示基础参与条件。

参考匹配分将实际差异单独保留。夜间正手相对参考的 20.58 分扣分中，站距贡献 4.91 分，左肩高举贡献 3.88 分，左膝屈曲贡献 2.92 分。各阶段的角度、肩宽归一距离与具体扣分可在对照页复算。

同一德约视频的第三次双反对照第二次双反，匹配分为 **63.62**；两段原动作分分别为 82.49 和 97.49。两次职业来源动作本身也有姿态差异，参考匹配分表示与选定动作的接近程度。第一双反使用左侧测量手，第二双反使用右侧测量手，系统按测量手不一致返回无可比分。正手自身比较得到 100 分，标记为数学一致性检查，不计入独立来源验收。

c235 的 **124.533–125.467 秒**候选原动作分为 64.65。扩大至 122.5–127.5 秒并逐帧检查后，确认该段为持拍复位，缺少独立的引拍、前挥和随挥序列，因此在参考验收层排除。原检测记录、原分和四张画面证据继续保留；本轮没有把这一排除结果描述为动作检测器已消除同类误检。

## 比较规则与系统实现

新增 `rallymate_scoring.reference_comparison.compare_action_to_reference`。比较使用双膝屈曲、双肘屈曲、双肩高举、肩髋分离和肩宽归一站距共八项测量。十个阶段是原报告的重叠运动学观察窗；测量覆盖率与真实触球、受力事件的核验分别记录。

阶段权重采用参考指南中的分组：M04–M06 共 40%，M07 为 25%，M08 为 20%，其余五阶段共 15%。可测指标分为下肢 30%、躯干 30%、上肢 40%，组内等权。角度容差 5°、尺度 45°；站距容差 0.1 肩宽、尺度 1 肩宽。这些子项数值是明示的工程政策，`coach_calibrated=false`，不作为原文中的实测常数。

单项距离为 `clamp((abs(测试值−参考值)−容差)/尺度, 0, 1)`。总分按可用权重归一，缺测保留在覆盖率分母；共同覆盖至少 80% 且 M04–M08 均有测量才给匹配分。输出保存原始权重、归一权重和实际扣分贡献，满足 `100−Σ扣分=匹配分`。

比较严格核对技术类型、测量手、人物、视频 SHA、帧集合、阶段时钟、单位和测量统计。内部矛盾的分位数、删帧后伪造的覆盖率、指向未观测帧的阶段锚点均被拒绝。`numpy.float64` 内存数值与保存后的 JSON 数值产生完全相同的比较结果。原动作分、参考匹配分和等级权重分别保留，职业身份不进入计算。

系统提供只读接口：

```text
GET /v1/jobs/{job_id}/reference-comparison
    ?episode_id={candidate_episode}
    &reference_job_id={reference_job}
    &reference_episode_id={reference_episode}
```

接口沿用现有服务鉴权，双方任务须已完成；从原生输入调用当前评分器重算。网页网关支持该路由，未改变推理和资源调度。交互对照页可切换配对、查看十阶段、八指标、原帧联系表及排除样本。
